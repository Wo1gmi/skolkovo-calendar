# skolkovo-calendar

Синхронизация расписания СКОЛКОВО с Google Calendar и уведомления об изменениях в Telegram.

## Проверить и обновить расписание

В GitHub откройте **Actions → Test and update schedule → Run workflow**.
Выберите ветку с изменениями и запустите проверку.
После первого слияния workflow в `main` он появится в списке Actions.

Запуск выполняет все тесты проекта, затем записывает актуальное расписание в календарь.
При изменениях отправляет обычные уведомления, а в конце — сообщение с датой,
временем и количеством добавленных, обновлённых и удалённых событий.
Даже если изменений нет, итоговое сообщение придёт.
Если тесты не проходят, календарь не обновляется.
При ошибке синхронизации уже выполненные изменения могут остаться в календаре;
запуск отмечается как неуспешный.

Для запуска используются те же секреты GitHub, что и для обычной синхронизации:
`SKOLKOVO_EMAIL`, `SKOLKOVO_PASSWORD`, `GOOGLE_SERVICE_ACCOUNT_JSON`,
`GOOGLE_CALENDAR_ID`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
Удаление отменённых занятий зависит от настройки `ENABLE_DELETIONS`.
Ручные цвета не сбрасываются. Задания LMS этот запуск не синхронизирует;
для них остаётся отдельный workflow **LMS assignments**.

Локальный запуск с настроенными переменными окружения:

```sh
pip install -r requirements.txt -r lms-requirements.txt
python run_checks.py
```

Это запуск с записью в настоящий календарь и отправкой сообщений.
Для проверки кода без обновления календаря используйте:

```sh
python -m unittest discover -v
```
